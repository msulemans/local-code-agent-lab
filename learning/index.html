    Lesson 01 · Anatomy

    A model predicts.
    A runtime takes responsibility.

    A coding agent is a controlled loop around a model. Click a component to see what it owns—and what it must never be trusted to own.

    THE SIMPLEST CORRECT EXPLANATION

    The model is the strategist. It suggests the next move. The runtime is the referee and recorder. It checks the suggestion, executes only allowed actions, returns evidence, counts the budget, and decides when the run ends.

    Path escape

    ../ and absolute paths could leave the repository. The runtime rejects them before reading.

    ◇

    Symlink

    A safe-looking file can point elsewhere. Version 1 rejects every symlink component.

    •••

    Secret path

    .env, keys, credentials, model artifacts, and VCS internals never become observations.

    …

    Truncation

    A bounded result may be incomplete. The agent must narrow its next action instead of pretending it saw everything.

    A capability label is not a safety proof. Reads can leak data or inject hostile text; patches can exceed their intended scope; tests can become process, filesystem, or network escapes. Every tool therefore needs its own semantic contract and limits.
